Dosing Wizard V2

Thirty-one screens. Hand-written sample data throughout. They exist so the interface can be judged before implementation, and so the implementation has a target.

What this set is. PR #6 built eleven screens and the visual language they are drawn in. That language and its substance carry across unchanged. What is added is the surfaces the V1 application had and PR #6 did not — taken from docs/migration/V1-APPLICATION-SALVAGE.md §12 — dressed in the new look rather than the old one.

The five tabs

Today · Test Lab · Tasks · History · Tools. Settings sits behind a gear rather than taking a fifth of the bar. Tools is present, disabled and labelled “later” — a calculator must never look like advice, so the destination is reserved now rather than retrofitted.

PR #6’s Log tab is dissolved: readings go to Test Lab, maintenance goes to Tasks. Nothing lost a home; the entry form is still there, reached from both.

The moments — ported from V1, not rebuilt

These four run. Their timing constants, easing curves, delays and progress-driven geometry are transcribed from V1 source and live in tokens.css; the driver reads them from there at run time. What changed is only what they are drawn with.

  • ◉ The reading arrives on its own historyChart draw, travelling dot and counting number all read from one progress value — the fix that stopped the dot running ahead of its own line. ›
  • ↑ The dose expectationA dose change is a prediction as much as an action. Stated before the next reading arrives, and never revised afterwards. ›
  • ✓ Task completionThe run of completions and the actual intervals between them, which are often not the interval that was set. Shown without comment. ›
  • ◎ The panel arrivesElements count in, the ones outside reference are named, and what moved since the last panel is shown with its direction. ›

How it is built

tokens.cssEvery colour, radius, shadow, size — and every timing valueincluding all four moments, ported
app.cssShared componentsstructure only; no literal appearance value
moments.jsThe four momentsthe only script; reads its timing from tokens.css
check-plain-english.pyFails if contract vocabulary is visibleowner decision 9, pinned rather than promised
CONTRACT-GAPS.mdThings the screens cannot expressrecorded, none resolved
Nothing here is authority for anything. No engine, no persistence, no framework beyond one small script for the moments. Every number is hand-written sample data, and no threshold, band edge, cadence or dosing figure on any of these screens governs behaviour anywhere.
