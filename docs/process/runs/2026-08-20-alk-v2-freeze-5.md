## Stage 1 — admissibility

**This run edits `docs/canon/`, which `/implement-chemistry` step 7 otherwise
forbids.** That is the whole point of the task and it is admissible for one
reason only: `ALK_V2_FREEZE_4`'s own reopening rule provides for exactly this,
and the owner invoked it.

> Any future Alk behavioural or load-bearing completeness change requires: exact
> affected rule IDs; concrete failure scenario; canon vs implementation
> classification; affected coverage fixture updates; `IMPACTS_FROZEN_ALK` where
> caused by a shared change; Alk V2 Freeze 5 or later.
> — canon, `PART III — ALK V2 FREEZE 4 DECLARATION`, *Reopening rule*

Each requirement is met by this run: the affected rule IDs are enumerated in the
Freeze-5 declaration; the concrete failure scenario for every decision is the one
already recorded in `ALK-V2-OPEN-ISSUES.md`; the classification is
`CANON_DEFECT` + `OWNER_DECISION_REQUIRED` in each case; the coverage fixtures
are updated in this commit; no shared rule body changed, so
`IMPACTS_FROZEN_ALK` does not arise.

The other admissibility test in step 1 — *every rule this change implements must
be stated in current frozen canon* — is inverted here. This run is the mechanism
by which rules **become** canon. The applicable constraint instead is the one in
`CLAUDE.md`: adopted chemistry may not arrive by invention. It arrives here by
**owner decision through a governed reissue**, which is the only path
`CLAUDE.md` recognises for a rule with no prior freeze.
