forbids.** That is the whole point of the task and it is admissible for one
reason only: `ALK_V2_FREEZE_4`'s own reopening rule provides for exactly this,
and the owner invoked it.

> caused by a shared change; Alk V2 Freeze 5 or later.

Freeze-5 declaration; the concrete failure scenario for every decision is the one

`CANON_DEFECT` + `OWNER_DECISION_REQUIRED` in each case; the coverage fixtures
are updated in this commit; no shared rule body changed, so
`IMPACTS_FROZEN_ALK` does not arise.

The other admissibility test in step 1 — *every rule this change implements must
be stated in current frozen canon* — is inverted here. This run is the mechanism
by which rules **become** canon. The applicable constraint instead is the one in
`CLAUDE.md`: adopted chemistry may not arrive by invention. It arrives here by
**owner decision through a governed reissue**, which is the only path
`CLAUDE.md` recognises for a rule with no prior freeze.

### Arithmetic

Every derived number in the new and rewritten fixtures was computed independently
(Theil–Sen, `sigma_resid = 1.4826·MAD`, `sigma_point = max(0.10, sigma_resid)`,
`Sxx`, `sigma_S = sigma_point/√Sxx`, `S_supported = sign(S)·max(0, |S| − 1.28·sigma_S)`)
before being written, not read back from the fixtures.

Three defects were found this way and fixed:

1. **`AD-MNT-006` / `AD-MNT-007` were internally inconsistent** (pre-existing).
   Inputs `7.6, 7.75, 7.9` give `S_TS = +0.075`, while the fixture's own
   expectations stated `+0.15` and a supported slope of `0.104745166`, which only
   follows from `+0.15`. Inputs corrected to `7.3, 7.6, 7.9` and the mirror to
   `9.7, 9.4, 9.1`, which reproduce the stated slopes exactly. Both fixtures were
   being rewritten for F5-05 anyway.
2. **`OI-INDEPENDENCE-001`'s narrative arithmetic was wrong** (pre-existing). It
   quoted `Sxx = 6.3889 / 10.25` and `sigma_S = 0.039556 / 0.031235` for the
   backward-greedy and keep-all readings; the stated cluster times give
   `6.1667 / 9.6875` and `0.040269 / 0.032129`. Corrected in place with the
   correction recorded, since the block is now historical. The argument the
   scenario makes is unaffected.
3. **`AD-DEL-002` was a dangling fixture reference** (pre-existing) — no such
   fixture body exists, yet the `AD-` prefix reads as a committed golden. Renamed
   to the `DEL-002` unit-test-slot convention that `ALK-V2-TEST-MATRIX.md` §10
   already documents, and `ALK-035` keeps `WG-ALK-047` and `AD-SEG-003` as its
   committed coverage.
